# Content provenance

Way to Asia is being developed as part of an authorised collaboration with Japanspecialist. Japanspecialist is used as a product and editorial reference for catalogue structure, tour-type taxonomy, filtering patterns, itinerary information, destination guidance and the consultation journey.

Reference surfaces include:

- <https://japanspecialist.com/home>
- <https://japanspecialist.com/tours>
- <https://japanspecialist.com/individual-tours>
- <https://japanspecialist.com/deluxe-group-tours>
- <https://japanspecialist.com/excursions>
- <https://japanspecialist.com/blog/all-articles>

The current Way to Asia demonstration uses original brand copy and royalty-free Unsplash photography. If collaboration-supplied Japanspecialist text or media is imported later, record the source URL, asset owner, approval reference, import date and permitted channels on the relevant Sanity document. This keeps the demonstration auditable and ready for eventual production use.

Never import customer data, unpublished commercial terms, analytics, credentials or supplier-confidential material into the public GitHub repository. Those belong in approved private systems and Cloudflare secrets.
